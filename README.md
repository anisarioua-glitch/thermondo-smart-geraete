# thermondo smart – Geräteliste und Anleitungen

Statische Seiten, ohne Server, ohne Datenbank. Entwurf.

| Datei | Inhalt |
|---|---|
| `index.html` | Kompatibilitätsliste: 292 Geräte, Kategorie-Buttons, Suche, Filter |
| `mx400/index.html` | Animierte Anleitung: Buderus MX 400 Gateway mit thermondo smart koppeln |

## Einbinden auf thermondo.de

Im Wagtail-Entwurf „Unterstützte Geräte (Entwurf)“ die Pages-Adresse dieses
Repositories in den vorhandenen **Iframe-Block** eintragen und den Entwurf speichern.
Der Kunde sieht dann `thermondo.de/kompatibilitaetsliste/`, der Inhalt kommt von hier.

## Verlinkung

Die Liste verlinkt die Buderus-Wärmepumpe **relativ** auf `mx400/`.
Dadurch funktioniert der Link an jedem Ort, solange beide Dateien nebeneinander liegen.
Alle übrigen Geräte stehen bewusst auf „folgt“.

## Hinweis

Persönliches Repository, angelegt als Machbarkeitsnachweis.
Vor einem Livegang gehören diese Dateien in die Hand des thermondo-Web-Teams.
